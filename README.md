# Hang Daro Portfolio

A pixel-art, game-style portfolio for Hang Daro, Android Development Engineer (Flutter & native).

It's a single static page (`index.html`) built with HTML, CSS and JavaScript. The animated meadow in the hero is drawn on a `<canvas>`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

## Deploy

- **Vercel:** import this repo; no build settings needed.
- **GitHub Pages:** Settings → Pages → deploy from the `main` branch, root folder.
